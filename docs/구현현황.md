# 구현 현황 — 내전 운영 서비스 v2

작성 시작: 2026-11-05 · 범위: P4-7의 구현 0~7번과 그 뒤에 더한 기능, 운영하며 고친 것

이 파일은 입구다. 본문은 590KB까지 불어나 한 파일로 열기 버거워서 2026-11-20에 날짜 구간별로 `docs/구현현황/`에 나눴다(내용은 한 글자도 바꾸지 않고 자르기만 했다). 본문 안의 "맨 아래", "아래 절" 같은 말은 나누기 전 한 파일 기준이라, 지금은 대개 "더 뒤 구간 파일"을 뜻한다.

이 기록은 **만든 것, 확인한 것, 확인하지 않은 것**을 구분해 적는다. 1차본(11-05)의 검증은 모두 로컬 환경(로컬 Workers 실행 환경 + 로컬 D1, 헤드리스 Chromium)에서 했고, 운영 배포 이후의 기록은 각 절에 운영 확인 여부를 따로 적었다.

새 기록은 마지막 파일 끝에 덧붙인다. 마지막 파일이 150KB를 넘으면 그다음 날짜로 새 파일을 열고 위 표에 한 줄 더한다.

### 어디부터 읽을지

1. `README.md` — 무엇을 하는 사이트인지, 실행 명령, 사용할 때 알아 둘 동작.
2. `docs/배포안내.md` — 운영 배포 순서, 비밀값, 사고 대응.
3. 위 표의 **마지막 파일 끝(가장 최근 날짜) 절** — 지금 검증 상태와 남은 것. 앞쪽 절은 그때그때의 기록이다.
4. `docs/P2-도메인·상태·권한·저장.md` — 경기 상태·권한·요청 ID·버전 규칙(설계의 기준).
5. 코드 진입점 — 서버 `src/server/index.ts`(API 경로 전체), 화면 `src/web/App.tsx`(주소 → 화면).
