# 새 디자인 규칙 적용 계획 (2026-11-11)

기준: 저장소 맨 위 `CLAUDE.md`(강조색 골드, 파랑은 블루 진영 전용). 첫 화면 구조 시안은 골드 강조판으로 확정.
계획은 Fable 5.2가 조사해 세웠고(파일 수정 없음), 구현은 Opus 작업자가 단계별로 한다. 단계마다 테스트 → staging → 390·768·1440 사진 확인 → 운영 배포 → 커밋.
