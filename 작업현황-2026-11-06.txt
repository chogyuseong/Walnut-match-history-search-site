4. 중간에 멈춘 작업
==================================================
준비 화면 기능 6가지 (요청: "준비 화면 추가 기능 모두 다")
  1) 편성 균형 표시(두 팀의 티어 점수 합과 티어별 인원)
  2) 라인 맞대결 표시(같은 라인 두 사람의 상대 전적)
  3) 되돌리기 여러 단계(최근 5단계)
  4) 대기자와 교체(11명 이상일 때)
  5) 편성 이미지 공유(PNG)
  6) 같은 편성 경고(직전 경기와 팀 구성이 같으면 시작 전 확인)

- 진행 정도: 공용 계산 로직 일부만 작성된 상태에서 중단함
  (src/shared/draft.ts, merge.ts, rotation.ts 수정, src/shared/prepTools.ts 새 파일,
  test/draft-fuzz.test.ts 수정). 화면(Prep.tsx, Pick.tsx)은 손대지 않았음.
  이 상태에서는 대량 점검 테스트 2개가 실패했음(작업 도중이라 정상).
- 보관 위치: git 임시 보관함(stash)
    stash@{0}: "준비 화면 기능 6가지 - 중단 시점의 미완성 작업(공용 로직만, 화면 미착수)"
  꺼내려면: git stash pop      버리려면: git stash drop
- 이어서 하려면 이 보관분을 꺼내 이어가거나, 버리고 처음부터 다시 맡기면 됨.
  6가지의 세부 기준(티어는 비공개라 균형 표시는 기본 접힘, 대기자 자동 순환은
  만들지 않음 등)은 이 대화에서 정해 두었음.

5. 아직 정해지지 않았거나 확인이 필요한 것
==================================================
- 칭호 "떠오르는 강자": 임시로 붙인 이름. 구간이 6개가 되면서 "든든한 전우"와
  같은 방패·초록 엠블럼을 씀(색·엠블럼은 다섯 등급뿐).
- 승률 색: 다크·바이올렛 테마에서 낮은 승률 쪽이 기준 색과 꽤 비슷함.
  더 또렷하게 하려면 막대 바탕색을 어둡게 해야 함.
- 개인 통계의 "지금"(연속 기록) 타일: 라인 타일을 추가하면서 요약 위쪽 줄로 옮겼음.
  타일로 되돌릴지 미정.
- 서포터 횟수가 오르는 시점: 지금은 경기를 시작할 때. 결과 저장 때로 바꿀지 미정.
- 2025년 107경기의 날짜: 위 3-(2)의 추정 배치를 그대로 둘지, 12월 31일까지 펼지,
  시트에 실제 날짜를 채울지.
- 서버 집계: 한 모임이 2000경기를 넘으면 통계 계산을 서버로 옮기기로 기준만 정함.
- 복구 단위: D1 시점 복구는 DB 전체 단위라 모임 하나만 되돌릴 수 없음.
  서버가 모임별 백업을 보관하게 할지 미정.
- 문서에 아직 적지 않은 것: 3번의 자료 수정, 커밋 2380b98(칭호 구간 추가).
