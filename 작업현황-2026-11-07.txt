4. 운영 배포 전 사람이 할 일 (docs/배포안내.md)
==================================================
- npx wrangler r2 bucket create naejeon-prod-backups / naejeon-staging-backups, 수명 주기 30일 규칙
- npx wrangler d1 create naejeon-staging → database_id, PUBLIC_ORIGIN 채우기
- wrangler secret put SESSION_SECRET --env staging / production
  ※ SESSION_SECRET을 바꾸면 자체 계정 비밀번호가 전부 무효(페퍼). 안전하게 보관.
- staging에 먼저 배포 → 마이그레이션 0001~0021 → 스파이크 → 확인(로그인 CPU, CSP 헤더, 조회 304) → production
- SITE_ADMIN_ACCOUNT_IDS, src/web/legal.ts [채워야 함] 4개
- 첫 푸시 때 GitHub Actions CI 실제 동작 확인(로컬에서는 못 돌림. Node 22, workerd postinstall)
